## 📝 Problem Statement

Write a program to accept a float value and an integer as input. The integer represents the precision. Print the float value according to the precision.

## 🧪 Examples

### Example 1

**Input:**
```text
123.4567 2
```

**Expected Output:**
```text
123.46
```

### Example 2

**Input:**
```text
987.346732 3
```

**Expected Output:**
```text
987.347
```
