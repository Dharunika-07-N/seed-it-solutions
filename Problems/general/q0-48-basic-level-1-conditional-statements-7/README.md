## 📝 Problem Statement

Get three inputs in the format-integer,character,integer. The inputs are all seperated by spaces. Perform the operation with the integer values based on the
character(+,-,*,/). Display the calculated value as the output.
Ex : 23 + 45
o/p : 68

## 🧪 Examples

### Example 1

**Input:**
```text
6 * 4
```

**Expected Output:**
```text
24
```

### Example 2

**Input:**
```text
17 + 15
```

**Expected Output:**
```text
32
```
