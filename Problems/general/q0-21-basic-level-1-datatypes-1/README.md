## 📝 Problem Statement

Given 2 nos, Print the first number as a 5-digit Number and Print the Second number in the Next Line with 5 width space

## 🧪 Examples

### Example 1

**Input:**
```text
25 98
```

**Expected Output:**
```text
00025
   98
```

### Example 2

**Input:**
```text
12345 12
```

**Expected Output:**
```text
12345
   12
```
