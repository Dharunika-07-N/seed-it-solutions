## 📝 Problem Statement

Write a program to accept the array and count the number of odd and even numbers in the given array

## 🧪 Examples

### Example 1

**Input:**
```text
10
77 67 55 44 25 14 87 95 45 92
```

**Expected Output:**
```text
Odd = 7
Even = 3
```

### Example 2

**Input:**
```text
8
1 2 3 4 5 6 7 8
```

**Expected Output:**
```text
Odd = 4
Even = 4
```
