## 📝 Problem Statement

Find the max,min,sum and average of the given n numbers without using array.
Note: -1 will be the termination of the input.

## 🧪 Examples

### Example 1

**Input:**
```text
10 20 30 40 50 -1
```

**Expected Output:**
```text
Min = 10
Max = 50
Sum = 150
Average = 30.000000
```

### Example 2

**Input:**
```text
1 2 3 4 5 -1
```

**Expected Output:**
```text
Min = 1
Max = 5
Sum = 15
Average = 3.000000
```
