## 📝 Problem Statement

Given an integer value, if it is divisible by 3 print “Hi”, if it is divisible by 5 print “Hello”. If it is divisible by both print “HiHello”

## 🧪 Examples

### Example 1

**Input:**
```text
9
```

**Expected Output:**
```text
Hi
```

### Example 2

**Input:**
```text
10
```

**Expected Output:**
```text
Hello
```
