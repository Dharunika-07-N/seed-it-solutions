## 📝 Problem Statement

Given 2 integer input check whether the 2 input are "Equal" or "Not Equal" print the corresponding message

## 🧪 Examples

### Example 1

**Input:**
```text
-109 83839
```

**Expected Output:**
```text
Not Equal
```

### Example 2

**Input:**
```text
20 20
```

**Expected Output:**
```text
Equal
```
