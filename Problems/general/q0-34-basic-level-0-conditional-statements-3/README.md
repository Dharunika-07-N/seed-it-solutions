## 📝 Problem Statement

Given an integer input , whether the given input is "Positive" or "Negative" or "Zero" and print the corresponding message

## 🧪 Examples

### Example 1

**Input:**
```text
-2023
```

**Expected Output:**
```text
Negative
```

### Example 2

**Input:**
```text
2023
```

**Expected Output:**
```text
Positive
```
