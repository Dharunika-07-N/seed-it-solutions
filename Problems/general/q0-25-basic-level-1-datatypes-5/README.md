## 📝 Problem Statement

Scan a string and calculate its length in the same scanf statement. The string can consist of spaces also.

## 🧪 Examples

### Example 1

**Input:**
```text
Hello World
```

**Expected Output:**
```text
Hello World 11
```

### Example 2

**Input:**
```text
Hello SEED candidate
```

**Expected Output:**
```text
Hello SEED candidate 20
```
