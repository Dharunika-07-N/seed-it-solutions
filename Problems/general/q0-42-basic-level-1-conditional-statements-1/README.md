## 📝 Problem Statement

Based on the given marks, print the corresponding grade according to the following conditions
Given a particular marks, a grade is calculated as per the following table:
Score          Grade
1. marks>=91     A
2. 76<=marks<=90 B
3. 61<=marks<=75 C
4. marks<=60     D

## 🧪 Examples

### Example 1

**Input:**
```text
95
```

**Expected Output:**
```text
Grade A
```

### Example 2

**Input:**
```text
79
```

**Expected Output:**
```text
Grade B
```
