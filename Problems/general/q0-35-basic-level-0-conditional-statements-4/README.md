## 📝 Problem Statement

Given an integer value, check the given input is divisible by 3. If it is divisible print the message "The number is divisible by 3".if it is not divisible print the message "The number is not
divisible by 3 and gives a remainder _".

## 🧪 Examples

### Example 1

**Input:**
```text
465
```

**Expected Output:**
```text
The number is divisible by 3
```

### Example 2

**Input:**
```text
31
```

**Expected Output:**
```text
The number is not divisible by 3 and gives a remainder 1
```
